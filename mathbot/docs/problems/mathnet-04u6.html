Czech-Polish-Slovak Match Problem

Geometry > Plane Geometry > Triangles > Triangle centers: centroid, incenter, circumcenter, Euler line, nine-point circle, Geometry > Plane Geometry > Circles > Coaxal circles, Geometry > Plane Geometry > Quadrilaterals > Cyclic quadrilaterals, Geometry > Plane Geometry > Advanced Configurations > Isogonal/isotomic conjugates, barycentric coordinates, Geometry > Plane Geometry > Miscellaneous > Angle chasing · 2026-08-30

問題

$ABC$ を鋭角な不等辺三角形とする。$AB$ および $AC$ 上の点をそれぞれ $D$ および $E$ とし、$BD = CE$ が成り立つとする。三角形 $ABE$ および $ACD$ の外心をそれぞれ $O_1$ および $O_2$ とする。三角形 $ABC$、$ADE$、および $AO_1O_2$ の外接円が、$A$ とは異なる共通の点を持つことを証明せよ。

解答

$Z$を三角形 $ABC$ の外接円 $\omega$ の長い方の弧 $BC$ の中点とする。三角形 $ZDB$ と $ZEC$ は、辺 $BD = CE$ および $ZB = ZC$ が等しく、さらにそれらの間の対応する角が（いずれも $\omega$ の弦 $AZ$ 上にあるため）等しいことから、合同である。したがって $\angle ZDA = \angle ZEA$ が成り立ち、このことは四角形 $ADEZ$ が円に内接することを示している。ゆえに、四角形 $AO_1O_2Z$ が円に内接することを示せばよい。 $\omega$ の中心を $O$ とすると、$OO_1 \perp AB$ および $OO_2 \perp AC$ が成り立つ。$O$ と $O_1$ の $AC$ への射影は、それぞれ $AC$ と $AE$ の中点である。したがって、線分 $OO_1$ の $AC$ への射影の長さは $\frac{1}{2}CE$ である。同様の理由で、$OO_2$ の $AB$ への射影の長さは $\frac{1}{2}BD$ であり、仮定によりこれら2つの長さは等しい。さらに、$OO_1$ と $AC$ のなす角は、$OO_2$ と $AB$ のなす角と等しい。したがって、$OO_1 = OO_2$ である。 さらに、$\angle AOO_1 = \angle ACB = \angle O_2OZ$ が成り立つ（後者は $ZO \perp BC$ および $OO_2 \perp AC$ の帰結である）。よって、半直線 $OA$ と $OZ$ は、角 $O_2OO_1$ について等角共役である。$AO = ZO$ および $OO_1 = OO_2$ と合わせることで、 四角形 $AO_1O_2Z$ は等脚台形であり、したがって特に円に内接する。 これにより問題は解かれた。 三角形 $ABE$ と $ADC$ の外接円が $A$ とは異なる点 $F$ で再び交わるとする。このとき、三角形 $BFD$ と $EFC$ は、辺 $BD = CE$ が等しく、かつ対応する隣接角（すなわち $\angle FBD = \angle FEC$ および $\angle BDF = \angle ECF$）が等しいため、合同である。したがって、これらの三角形の $F$ を通る高さは等しく、それゆえ $AF$ は $\angle BAC$ の二等分線である。 次に、$SO_1FO_2$ が平行四辺形となるような点 $S$ を構成する。$S$ が求める点であることを示す。 $S$ が三角形 $AO_1O_2$ の外接円上にあることを証明するために、$AO_1 = FO_1$ および $AO_2 = FO_2$ より、三角形 $AO_1O_2$ と $FO_1O_2$ が合同であることに注目する。したがって、$AO_1O_2S$ は等脚台形であり、主張通り特に円に内接する四角形となる。この後、$AS \parallel O_1O_2 \perp AF$ であることが、本項で用いた事実から導かれることは有用である。 次に、$S$ が三角形 $ABC$ の外接円上にあり、かつそれが実際にその長い方の弧 $BC$ の中点であることを証明する。これはまた、必要に応じて $S \neq A$ であることも示す。最初の中間ステップとして、三角形 $O_1SB$ と $O_2CS$ が合同であることを観察する。実際、これらは2辺 $BO_1 = FO_1 = SO_2$ および $SO_1 = FO_2 = CO_2$ において等しい。さらに、これらの辺の間の対応する角は等しい。なぜなら、それらの $360^\circ$ への補角が以下の結果として等しいためである。 $$ \angle BO_1F = 2\angle BAF = 2\angle FAC = \angle FO_2C $$ および $\angle FO_1S = \angle SO_2F$。これで $\triangle O_1SB \cong \triangle O_2CS$ の証明が完了し、これにより $BS = CS$ が従う。さらに、$AF$ が $\angle BAC$ の二等分線であり $AF \perp AS$ であることから、直線 $AS$ は $\angle BAC$ の外角の二等分線である。以上のことから、$S$ は上述の点であることが得られる。$S$ が三角形 $ADE$ の外接円上にあるという事実は、最初の解答と同様にして示すことができる。 三角形 $ABC$ と $ADE$ の外接円の中心をそれぞれ $O$ および $P$ とする。直線 $OO_1$ と $O_2P$ （それぞれ $AB$ と $AD$ の垂直二等分線である）はともに $AB$ に垂直であり、それらの距離は $\frac{1}{2}BD$ である。同様に、直線 $OO_2$ と $O_1P$ はともに $AC$ に垂直であり、それらの距離は $\frac{1}{2}CE$ である。$\frac{1}{2}BD = \frac{1}{2}CE$ であるため、四角形 $O_1OO_2P$ は等しい高さを持つ平行四辺形、すなわちひし形である。したがって $OP$ は $O_1O_2$ の垂直二等分線であり、三角形 $ABC$、$ADE$ および $AO_1O_2$ の3つの外接円の中心はすべて同一直線上にある。これで主張は完了である（$AB \neq AC$ であるため、$A$ はこの直線上にはない）。
